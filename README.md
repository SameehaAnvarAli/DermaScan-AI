# DermaScan AI 🩺

### Explainable Skin Lesion Screening System

DermaScan AI is an AI-assisted skin lesion screening prototype that uses deep learning and explainable AI to classify dermatology images into seven lesion categories.

## 🚀 Live Demo

👉 [Open DermaScan AI](https://dermascan-ai-gnpf5ewprfzjmdzkgakdml.streamlit.app/)

## ✨ Features

- 🧠 EfficientNet-B0 deep learning model
- 🔬 Seven-class skin lesion classification
- 📊 Prediction probabilities
- 🔍 Image quality checking
- 🔥 Grad-CAM explainability
- 📈 Model evaluation with multiple metrics
- 🌐 Interactive Streamlit web application

## 🛠️ Technologies

- Python
- PyTorch
- EfficientNet-B0
- OpenCV
- NumPy
- Pandas
- Scikit-learn
- Grad-CAM
- Streamlit

## ⚠️ Disclaimer

DermaScan AI is an AI-assisted screening and educational prototype. It is not a medical diagnostic tool and should not be used to diagnose or treat a medical condition. Users should consult a qualified healthcare professional for medical evaluation.
